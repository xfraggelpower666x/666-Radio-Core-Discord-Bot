# Security And Secrets

No secret values may be written to repo files. SECRET_REF names include DISCORD_TOKEN, DISCORD_CLIENT_ID, DISCORD_GUILD_ID, RADIO_TEXT_CHANNEL_ID, ALLOWED_ROLE_IDS, SONICPANEL_DJ_USER, SONICPANEL_DJ_PASS, SONICPANEL_SKIP_BEARER_TOKEN, SONICPANEL_JINGLE_BEARER_TOKEN, SHOUTCAST_ADMIN_PASS, WEBHOOK_URLS, CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID, GITHUB_TOKEN, STREAM_ADMIN_PASSWORD, AUTODJ_API_KEY. Store values only in local env, host secrets, GitHub Secrets or Cloudflare Secrets.
