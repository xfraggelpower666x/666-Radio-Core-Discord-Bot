# Upload-Anleitung — Scriptable RadioBotAI Uploader

1. ZIP entpacken.
2. In Scriptable den Uploader `666 RadioBotAI GitHub Uploader v3.4` öffnen.
3. Repo-Profil `666RadioBotAI — eigener Worker/Bot` prüfen.
4. GitHub Token speichern, falls noch nicht gesetzt.
5. GitHub Verbindung testen.
6. `RADIOBOTAI ROOT ersetzen / bereinigen` wählen.
7. Den entpackten Ordner `666RadioBotAI_VOCARD_SOVEREIGN_ROOT_v1_1_0` auswählen.
8. Vorschau prüfen.
9. Exakt bestätigen:

```text
REPLACE RADIOBOTAI ROOT
```

10. Nach Upload Cloudflare Healthcheck testen:

```text
https://666radiobotai.666soundsdesign-broadcaster.com/health
https://666radiobotai.666soundsdesign-broadcaster.com/status
https://666radiobotai.666soundsdesign-broadcaster.com/dashboard
```
